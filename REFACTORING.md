# REFACTORING v4 — система анимаций

Предыдущие фазы (ужатие до ~5000, цвета, S1-модель, alt-tab каркас, Bug B)
выполнены и закоммичены; история в git log. Открытый Bug A (black flash)
заморожен — см. CLAUDE.md/CANDIDATES.md.

## Цель

Модульная система анимаций в духе hyprlang-анимаций (`animations.enabled`
мастер + каждый лист: enabled/duration/curve), ноль хардкода, осознание
вертикального/горизонтального стрипа. Функционал и внешний вид по умолчанию
не меняются (все новые анимации включены с разумными дефолтами).

## AN1. Каркас (первым)

- **Мастер-тоггл** `animations_enabled` (1): единственная точка душаева —
  `animDuration()`/`newCardDur()` возвращают 1мс при нуле ⇒ все существующие
  часы (timeline/tileClock/newCard/reflow) доигрывают за кадр. Отдельные
  ветки «если выключено» не расползаются по коду.
- **Реестр анимаций** в main.cpp (таблица как kIntCfg): для каждого leaf
  генерируются `<leaf>_enabled` (int 0/1), `<leaf>_ms`, `<leaf>_curve`
  (string). Листы см. ниже.
- **Кривые**: enum + `curveEval(id,t)` в overlay_gl.hpp (linear,
  easeOutCubic — текущая, easeInOutCubic, easeOutBack для попов).
  Tween::raw() применяет кривую по id — одна точка. Существующие
  easeOutCubic/easeOutBack вызовы переезжают на реестровые кривые.
- Дефолты листов сохраняют текущее поведение (duration→open_ms и т.д.).

## AN2. Свап на стрипе через ПКМ (новый бэкенд)

Сегодня RMB-дрог окна со стрипа = swapOnWorkspace с КАРТОЙ (последнее
фокусированное окно воркспейса). Добавить: RMB-дрог на **конкретный слот
другого окна** (любая карта) → свап именно этих двух окон:
- хит-тест слота в release-ветке StripWin (stripWinSlotRect уже есть);
- бэкенд тот же, что у swapTiles: `switchTargets(wa->layoutTarget(),
  wb->layoutTarget())` + replayReflow; фолбэк — обычный перенос (пустой
  партнёр / фуллскрин).

## AN3. Визуал свапов (стрип)

- **Hint режим B**: пока тащим на ПКМ над слотом чужого окна — НЕ зоны
  вставки, а обводка РЕАЛЬНОГО слота целиком (strokeRing) + подсветка
  исходного слота. LMB-дрог сохраняет сегодняшние 2-зоны.
- **Success-пульс** (anim_swap): после коммита оба слота проигрывают
  короткий pop (scale 1→1+k→1 вокруг центра слота, кривая easeOutBack,
  ~180мс по умолчанию). Один активный StripPulse{itemA,itemB,t0}; оси
  не касаются — масштаб центр-симметричен.

## AN5. Шаг воркспейса по стрипу (анимированный скролл)

`m_stripScroll` сегодня мгновенный (wheel clamp / центровый прыжок при
rebuild). Сделать целевой скролл: m_stripScrollTarget + догоняющий Tween
(anim_strip_step, easeInOutCubic, ~200мс) в updateAnimation; renderStrip/
stripCardAt читают текущее значение. Ось не важна — скролл всегда вдоль
главной оси ленты. Мгновенный режим (enabled=0) = сегодняшний clamp.

## AN6. Переход all↔one (население грида)

Сегодня новые плитки экспо-режима появляются одним кадром. Ввести
`Tile.appear` (0..1): стартует 0 для плиток, которых НЕ было в oldBoxes
при replayReflow, 1 — для бывших; едeт по anim_populate (staggered по
индексу, как tileProgress) с easeOutCubic; рендер умножает альфу превью и
масштаб от центра target (0.6→1). Обратно (all→one) — обратный ход тем же
механизмом (появление=исчезновение зеркально).

## Реестр листов (дефолты = текущее поведение)

| leaf | ms | curve | что |
|---|---|---|---|
| open | 300 | easeout | вход оверлея (бывш. duration) |
| close | 300 | easeout | выход |
| reflow | 300 | easeout | перетекание плиток (drop/sync/swap) |
| swap_pulse | 180 | back | пульс успеха свапа (грид+стрип) |
| strip_step | 200 | easeinout | скролл ленты при шаге |
| populate | 250 | easeout | население/разъезд плиток all↔one |
| new_card | max(120,dur) | back | «+» карточка (существует) |

Плюс `animations_enabled`. Старый `duration` остаётся алиасом на open/close
(читается если отдельные не заданы) — обратная совместимость конфигов.

## Приёмка

- Мастер-выключатель мгновенно делает ВСЁ статичным (включая существующие
  анимации) без визуальных артефактов.
- Вертикальный стрип: пульсы/скролл ведут себя идентично горизонтальному.
- Ни одной новой цветовой/геометрической константы вне реестра/конфига.
