## Обновление 2 (post claude_review.md)

- **Solitary/DS вычеркнуты окончательно** для нашего repro: оба пути жёстко
  завязаны на Fullscreen::getFullscreenWindow(); без фуллскрина не включаются.
  (Подтвердить dso/soli=0 в PRE-probe по всем сессиям.)
- **Новый главный кандидат: CDamageRing.** Ring глубины 3; rotate() съедает
  m_current на КАЖДОМ beginRender. Один damage() в open() покрывает только
  первый потребивший его swapchain-image; остальные 1-2 образа могут
  презентоваться stale (вплоть до never-composited) — ровно «1-3 чёрных
  кадра». Фикс: `m->m_forceFullFrames = 3` в open() (ea8891e, патч внешнего
  ревью; цитаты сверены с pinned). Ждёт покадрового подтверждения.
- **render:new_render_scheduling = TRUE на этой машине** (Клод считал дефолт
  false и вычеркнул пункт 4 — здесь он ОТКРЫТ): асинхронный explicit-sync
  commit-путь активен. Дешёвый эксперимент при сохранении блинка после
  ea8891e: `hyprctl eval 'hl.config({ render = { new_render_scheduling = 0 } })'`
  → повторить тогглы.
- DS-leave без forceFullFrames — реальный гэп Hyprland (апстрим-репорт,
  вне нашего репо).
